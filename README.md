# AMX Academia — Portfólio

Este projeto consiste em uma interface web mobile-first para o gerenciamento de presenças em academias. Desenvolvido para atender às necessidades específicas da **Amx Brasília**, o software facilita o registro diário de frequência dos alunos, suportando turmas regulares e alunos avulsos.

### Características Técnicas

- **Interface:** SPA (Single Page Application) construída com **React** (via CDN para leveza).
- **Backend:** API REST desenvolvida em **Node.js/Express**.
- **Persistência:** Integração com banco de dados **MySQL**.
- **Funcionalidades:**
    - Autenticação de usuários com diferentes perfis (Líder/Instrutor).
    - Registro de presença automático (UPSERT).
    - Gestão de alunos avulsos provenientes de outras turmas.
    - Autosave com feedback visual.

# AMX Academia — Portfolio

This project is a mobile-first web interface for attendance management in martial arts academies. Developed to meet the specific requirements of **Amx Brasília**, the software streamlines daily student attendance tracking, supporting regular classes and guest students.

### Technical Highlights

- **Frontend:** SPA (Single Page Application) built with **React** (loaded via CDN for efficiency).
- **Backend:** REST API developed in **Node.js/Express**.
- **Persistence:** **MySQL** database integration.
- **Features:**
    - User authentication with distinct roles (Leader/Instructor).
    - Automatic attendance recording (UPSERT).
    - Guest student management for inter-class attendance.
    - Autosave functionality with visual feedback.
